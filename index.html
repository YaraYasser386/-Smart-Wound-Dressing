Concept overview

Smart Wound Dressing

This interactive concept demonstrates how a connected dressing might present selected environmental measurements, trends, notifications, and a patient-facing interface. It combines a responsive frontend, local browser persistence, and an optional local backend API. All displayed measurements are synthetic, generated for demonstration, and are not obtained from hardware or a patient.
