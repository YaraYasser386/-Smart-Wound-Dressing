SMART WOUND DRESSING — MOBILE STATIC PROTOTYPE

1) Extract this ZIP.
2) Open index.html in a browser, or upload index.html to the root of your GitHub repository for GitHub Pages.
3) The demo readings update automatically according to the refresh interval in Settings. The dressing color follows the simulated pH value.

All readings are simulated for an academic demonstration only. This is not a medical device and does not diagnose infection.
